Fix Windows setup buttons and HidHide discovery. The app now searches the actual bundled HidHide 1.5.230.0 x64 installation path and the newer official layout. Scanner subprocesses receive end-of-input so HidHide can finish instead of waiting until timeout. Scan, launch, and setup-check actions show visible progress, results, and errors. Read-only scanning and setup checks remain available during forwarding, with an explicit instruction to stop before applying routing. A failed scan no longer silently launches a second scan. Install / repair HidHide remains available if its tools are missing. Includes the faster jitter controls from 2.3.4.
