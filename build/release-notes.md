Jitter speed now supports 0.2–60 changes per second, with Slow (1), Quick (8), Fast (16), and Very fast (32) presets. Speed changes preserve the selected jitter strength. Timing retains fractional elapsed time so fast jitter does not slow down on uneven helper updates. Existing saved speeds are preserved. After choosing a preset while forwarding, click Apply edited settings to output. This release also includes the Connect & set up driver and HidHide workflow from 2.3.3.
